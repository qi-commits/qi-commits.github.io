## About

我是一名专注于复杂 B 端系统与增长投放的产品经理。

过去 3 年，我先后负责业财结算平台、分账中台与广告投放平台，处理过投放自动化、智能盯盘、渠道接入、佣金结算、分账与开票等复杂业务场景。擅长从混乱的业务流程中提炼标准能力，围绕用户旅程搭建统一入口、实体模型与可审计闭环。

工作中，我将 AI 融入调研、Demo、PRD、培训与交付；工作之外，借助 Cursor / Codex 独立完成小程序上架、Chrome 扩展开源、内容引擎与个人网站等实践，持续拓展产品经理的交付边界。

## Selected work

### NovaUG 智投 · 策略包自动投放

将多媒体买量策略拆解为「规则组 → 策略包 → 账户绑定 → 日志」四层模型，建设可复用、可批量、可追溯的自动投放工作台。

`策略引擎` `广告基建` `自动盯盘` `多媒体投放`

- 沉淀有效策略包 **61 个**、有效规则组 **123 个**，支持 **5 个媒体**
- 试点账户：头条消耗 **5.5 万**、ROI **1.14**；快手短剧消耗 **2.6 万**、ROI **1.04**
- 7 日自动开启潜力广告 **24,224 条**，精准关停劣质广告 **1,169 条**，挽回无效消耗 **6,234 元**

### 多 Agent 智能投放 · 最优参数与素材

设计数据分析、素材分析、广告搭建、广告调优四类 Agent，由统一控制中心串联“效果分析—素材筛选—模板提炼—参数优化—广告提交—效果回收”完整链路。

`Agent 架构` `Prompt / Skills` `MCP 编排` `起量优化`

- 任务完成度：**80%**
- 上下文传递完整率：**90%**；工具调用准确率：**100%**
- 工具调用成功率：**80%**；参数及素材准确率：**100%**
- 测试账户（10）消耗：**1424**

### 店东看懂账 · 装修业务

从用户调研、指标字典到移动端结算体验重构，让店东在手机上也能看清账、对完账。

`用户旅程` `佣金结算` `移动端` `体验重构`
