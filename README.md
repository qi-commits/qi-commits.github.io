## About

这是一个面向产品经理个人品牌的交互式作品集，聚焦复杂 B 端系统、增长投放与 AI 协作交付。

作品集不公开个人姓名、联系方式、精确履历时间或业务敏感指标；通过场景、方法、系统结构与交付方式，呈现产品思考和执行能力。

## Design direction

### 01 · Editorial minimalism

整体采用克制的编辑感排版：大留白、清晰的网格、低饱和背景与高对比文字，减少装饰性元素，让内容、结构和交互成为视觉主角。

### 02 · Soft glass + spatial depth

关于我模块使用轻量的磨砂玻璃卡片、柔和品牌色光晕、环境阴影和景深关系。卡片不追求厚重的拟物挤压，而更接近轻薄的玻璃屏幕，在保持统一材质的同时，用品牌色建立细微识别度。

### 03 · Motion as navigation

动效不是单独的装饰，而是内容浏览的导航方式。经历时间线以 3D 环绕轨道组织信息，卡片会随鼠标或触控移动，位于视觉焦点的经历被放大，其余内容自然退到空间背景中。

### 04 · Content before decoration

每个项目都围绕“背景—职责—过程—结果”的叙事结构展开。项目视频、真实界面、具象化业务场景与结构化文字共同组成内容证据，避免只展示概念性的视觉包装。

## Interaction features

- **3D 个人经历时间线**：通过环绕式卡片表达职业路径，支持鼠标移动、拖拽、滚轮与键盘操作。
- **焦点卡片机制**：当前卡片自动进入视觉中心，获得更清晰的层级、比例与品牌色光晕。
- **景深与动态模糊**：背景卡片根据空间位置降低清晰度，强化前后关系，让轨道更像连续的空间结构。
- **项目预览层**：项目卡片可展开为视频、交互 Demo、截图步骤与结构化说明，浏览路径从概览自然进入细节。
- **3D 人物交互**：首页使用可交互 3D 角色承载个人识别，支持轻量视线跟随与点击动作，同时保留低动态偏好下的静态体验。
- **主题适配**：页面支持明暗主题切换，时间线、卡片、光晕与文字对比度会同步调整。
- **响应式布局**：桌面端强调空间感和轨道关系，移动端优先保证内容可读性、触控范围与加载体验。

## Selected work

### 策略包自动投放平台

将多媒体买量策略拆解为“规则组 → 策略包 → 账户绑定 → 日志”的层级模型，建设可复用、可批量、可追溯的自动投放工作台。

`策略引擎` `广告基建` `自动盯盘` `多媒体投放`

### 多 Agent 智能投放

设计数据分析、素材分析、广告搭建、广告调优四类 Agent，由统一控制中心串联“效果分析—素材筛选—模板提炼—参数优化—广告提交—效果回收”的完整链路。

`Agent 架构` `Prompt / Skills` `MCP 编排` `起量优化`

### 业财与分账中台

围绕多业务、多角色、多口径的佣金结算场景，梳理用户旅程、实体关系、指标字典与数据流，沉淀账单、对账、开票、收付款与退款等模块化能力。

`用户旅程` `佣金结算` `数据中心` `平台化建设`

## Career perspective

职业经历覆盖直播、内容、电商、房产服务与广告科技等业务环境，工作角色从内容与运营逐步延伸到平台产品、业财中台和智能投放。

相比罗列公司名称和时间，我更希望通过作品呈现这些经历带来的方法沉淀：

- 从业务现场提炼可复用的产品模型
- 从复杂规则中建立统一入口与可审计闭环
- 从一次性交付中沉淀平台能力、模板与标准流程
- 用 AI 缩短从问题理解到可验证方案的距离

## Outside the role

产品能力不只存在于 PRD 里，也存在于一个被真正做出来、跑起来、交付出去的作品中。

- **品牌官网**：从信息架构、视觉方向到交互实现，完成一套可浏览的品牌体验
- **Chrome 扩展**：将局部录屏需求做成轻量、可用的浏览器工具
- **游戏内容引擎**：连接热点采集、AI 草稿生成、内容审核与多平台发布
- **生活服务小程序**：从需求定义、交互设计到独立上架，完成产品闭环

## Repository notes

这个仓库不是一个单纯的静态页面，而是一份可交互的产品作品。

它把个人经历、业务项目、交互实验与 AI 协作过程，整理成一个可以被浏览、理解和验证的产品叙事。实现层面使用 Next.js、React、Tailwind CSS 与 Three.js，配合静态资源、视频预览和局部交互 Demo，形成轻量但有空间感的个人网站。

> **Structure is a product decision.**
